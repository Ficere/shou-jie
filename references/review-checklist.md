# 逐条审查清单

本清单是审查和谈判设计，不是条款效力判定表。每行都要结合定义、除外条款、救济和关联文件，不用“市场惯例”替代论证。

## 主体、资金与交割

| 模块 | 核查内容 | 优先争取的设计 |
|---|---|---|
| 主体和签字 | 公司、创始人、配偶、平台、高管、关联方的签署身份；保证与共同债务是否混写；平台 GP 个人敞口 | 只让实际义务人签对应义务；删除无关第三方兜底；签字页不得扩大正文责任 |
| 估值与出资 | 投前/投后、实缴/认缴、增资/老股、币种、期权池、完全摊薄口径、资本公积与持股比例 | 列计算表及交割后 cap table，解释期权池扩张由谁承担 |
| 先决条件 | “令投资人满意”、投委会未批、投资人单方弃约；排他开始与确定出资不匹配 | 把内部审批尽量前置，条件可验证，最后期限、豁免权与终止后果明确 |
| 分期付款 | 每期金额、日期、里程碑验收人、异议和补救；第一期前股权是否全给；资金断档 | 付款和股权分批匹配；未投部分可停止但不把已投部分自动债权化；核算最低运营资金 |
| 对等救济 | 投资人迟付与公司迟延工商的责任；解除、费用、已登记未付款的处理 | 对等但按违约性质设计；不要让公司在资金未到账时承担全额履约 |
| TS | 有约束条款、排他期、自动续期、费用发票、费用上限、解除与预约义务 | 不因标题“无约束力”忽略具体条款；越早处理个人责任越好 |

## 回购与个人责任

| 模块 | 核查内容 | 优先争取的设计 |
|---|---|---|
| 责任性质 | 独立回购、保证、补充、差额补足、损害赔偿是否并存 | 经营失败不由个人保本；如无法删除，再谈有限责任及触发顺位 |
| 公司回购 | 公司类型、资本维持、减资/股份回购条件、债权人保护、决议与资金来源 | 把法定程序和协作义务写清；程序未完成不能自动转成个人无条件全额清偿 |
| 触发条件 | IPO 截止、业绩、重大不利变化、离职、控制权、交叉回购、基金到期、主观判断 | 按可控制性和重大性逐项谈；排除纯募资端压力；可补救违约设补救期 |
| 技术里程碑 | 技术失败是否直接现金回购；数据验收、质量、客户签约是否可控 | 定义客观验收、独立复核和变更机制；柔性指标也可能是刚性对赌 |
| 金额上限 | 本金、利息、罚息、赔偿、律师费、税费、各轮各人是否共享上限 | 明确总量而非每项上限；覆盖同一事件替代请求，防止重复补偿 |
| 财产范围 | “以股权价值为限”与“仅对股权/实收变现价款追索”的区别 | 责任金额与责任财产分别写；列明变现后不足消灭机制，但不保证排除法定执行 |
| 变现机制 | 股权范围、估值时点、评估争议、买方、转让限制、税费、无买家、投资人阻挠 | 定合理协作和退出流程；无买家不自动变成个人现金债务；不得允许恶意低价处置 |
| 价格及费用 | 单复利、起止日、利息基数、分红、部分退出、违约金重复计算 | 按实际到账和未回收本金算；列抵扣顺序；普通投资回报与违约责任分开 |
| 行权与时效 | 触发知悉、通知送达、权利窗口、付款期限、保证期间、诉讼时效 | 各期限分列，说明起算与效果；不要把行权窗口等同诉讼时效 |
| 配偶家庭 | 配偶同意函是否含保证、共同债务或追认；债务人共有财产份额 | 删除配偶担保和共同承诺；“个人债务”表述不能保证家庭财产完全隔离 |
| 例外和免责 | 宏观/行业变化、投资人行为、欺诈等例外；因果关系、证明和争议程序 | 具体定义、按影响顺延，保留争议解决；不把市场下行当然等同不可抗力 |

## 经济收益、治理与退出

| 模块 | 核查内容 | 优先争取的设计 |
|---|---|---|
| 清算优先 | 倍数、计息、参与型/非参与、封顶、轮次顺序、视同清算 | 可用 1 倍非参与作谈判起点而非法定标准；禁止越过公司债权人顺位；不设个人补差 |
| 多权叠加 | 回购、清算优先、赔偿、分红、退出对价是否重复获得 | 统一扣减、互斥选择、同一损失不重复受偿；解释跨轮优先顺序 |
| 反稀释 | 完全棘轮/加权平均、公式、补偿人、员工池和战略发行例外 | 广义加权平均可作起点；核对分母口径和补股税费，别只看名称 |
| 最惠国 | 追溯前轮、选择性摘取优惠、无时限、经济/治理权自动升级 | 限同类同阶段、期限与完整条件包，明列不适用事项 |
| 治理与否决 | 董事/观察员、法定表决要求、保留事项、日常预算、人事、僵局 | 列举重大事项、金额门槛、响应期限、失效门槛；不能用沉默视为同意绕过法定程序 |
| 信息与保密 | 查账、算法/客户/IP 披露、竞争对手投资、信息接收方 | 最小必要信息、目的和接收方限定、隔离及保密；不把董事个人承诺混为基金义务 |
| 股权流转 | 优先购买、共同出售、拖售、创始人锁定、违约离职 | 通知和失权清晰；拖售设门槛、公允价格、利益冲突排除；不由创始人接盘未随售部分 |
| 激励和 IP | 创始人反向归属、离职折价、竞业、已有 IP 与职务成果 | 按离职原因分层，补救和回购价合理；不把个人全部历史成果笼统归公司 |
| 投资人承诺 | 资源导入、后续跟投、董事履职、保密是否有主体/期限/验收 | 资源承诺分“尽合理努力”与结果义务；基金另行投资需审批的不作无条件承诺 |
| 柔性退出 | 延期、分期、减息、S 交易、后续轮转让、新主体入股 | 列为协商选项；分别取得基金授权、债权债务处理与国资/税务/IP 核验 |
| 管辖与文本 | 仲裁/诉讼冲突、送达、语言优先、强制执行公证、章程效力、签署授权 | 统一路径和文本；识别加快执行的安排；不宣称写入章程即可对抗一切第三人 |

## 文件群联动核验

1. 给文件编号，列明签署人、版本、优先级和被替代条款。
2. 检查“除另有约定”“不影响其他权利”“无限责任例外”“赔偿独立存续”等绕行。
3. 将总上限、有限追索、抵扣、失效规则贯穿全部同类责任文件；不机械把所有商业约定复制进章程。
4. 核验修改是否获得受影响方同意；侧函、历史轮次和担保函未给出时明确不能排除残留责任。
5. 复核股东协议、章程的公司治理要求、内部约束和第三人效力，不能仅凭“有冲突时以本协议为准”结束分析。
